# MorrowLab brand assets

Original supplied artwork, copied without visual changes:

- `morrowlab-lockup.png`: full horizontal mascot + wordmark (desktop header).
- `morrowlab-mark.svg` / `.png`: transparent mascot (favicon, mobile header and Mac menu bar).
- `morrowlab-app-icon.svg` / `.png`: peach square icon (touch icon, native app icon).

The wordmark includes unused transparent space on the right. Header CSS frames the visible logo
without stretching or modifying the image. The Mac packaging script derives `.icns` sizes from the
original app-icon PNG. Rebuild the companion to include updated native icons in its download.
